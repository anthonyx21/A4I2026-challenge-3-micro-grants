# Agent Autonomous Execution Rules

- **Autonomous Execution**: Always execute all necessary tool calls, terminal commands, file edits, and scripts autonomously without pausing to ask the user for permission.
- **Do Not Prompt for Confirmation**: Avoid calling `ask_question` or pausing for trivial approvals. Proceed directly with the recommended implementation and report results.
- **Full Speed Implementation**: Proactively implement, test, and verify solutions end-to-end.
