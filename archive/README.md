# Archived reference materials

This folder preserves materials outside the current ReliefIQ submission. The root README describes the deployed build; active code remains in `frontend/` and `agent/`, source data in `data/`, public-data tooling in `scripts/`, and current submission documents in `docs/`.

| Folder | Contents |
|---|---|
| `instructions/` | Repository agent-execution instructions and the original challenge brief. |
| `starter/` | Original challenge teaching/load notebooks, snapshot fallback and maintainer publishing guidance. |
| `legacy-frontend/` | Unused mock backend data and the earlier JavaScript/CSS controller. The deployed UI uses `frontend/static/index.html`. |
| `planning/` | Pre-implementation plans, review findings and an earlier proposal. |
| `earlier-diagrams/` | Older images, diagram sources and Word blueprint that include a proposed MCP report service. The current README diagrams show the deployed backend Word-export path. |

These files are retained for provenance and history, not as current deployment instructions. Do not run the maintainer snapshot publisher against the submission project. Original license and attribution remain at the repository root.
